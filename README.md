# Network Scanner

A fast network reconnaissance tool for beginners learning penetration testing concepts.

## Features

- Port Scanner — multithreaded scanning for fast results
- Service Detection — identify what is running on each open port
- Banner Grabbing — grab service banners for fingerprinting
- Clean web interface built with Flask

## Tech Stack

- Python
- Flask

## Installation

```bash
git clone https://github.com/ashagmp/network-scanner.git
cd network-scanner
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Then open your browser and go to `http://127.0.0.1:5000`
